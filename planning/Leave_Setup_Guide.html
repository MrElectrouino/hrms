How leave gets added, and what to set up

A step-by-step guide for the live (production) database: where the days come from, which settings decide it, and what to do on day one. Written for HR and System Admin, in plain words.

1. The short answer

Leave is never added just because someone joined. Days appear in an employee's balance in only three ways:

WayWhat adds the daysYou control it in
Automatic creditA job that runs every night, and the button Credit leave now. It gives each employee the days their leave policy says (or, if no policy covers them, the leave type's own setting).Administration → Leave setup → Policies, and System settings → Leave configuration
By handHR adds (or takes away) days for one employee, with a reason. Used for opening balances and corrections.Administration → Leave setup → Balances
Comp offWorking on a weekly off or a holiday: credited the moment a manager ticks Eligible for comp off while approving the day, if enough time was worked.System settings → Leave configuration → Leave year and comp off
If a leave type has no policy and its own setting is "No accrual", nobody ever gets days for it. This is the most common reason an employee cannot apply: the Send for approval button stays off because the balance is zero.

2. The nightly job

Every night at 02:30 (server time) the system does two things, in this order:

1. Expire old balanceAny credit past its expiry date is closed, and the ledger records what expired.
2. Credit leaveCredits the leave year (for "upfront" types) or each month so far (for "monthly" types) to every active employee who has joined.
  • Safe to repeat. Each credit carries a unique reference (employee, leave type, month or year). Running the job twice, or pressing Credit leave now several times, never credits the same days twice.
  • It catches up. If a month was missed, for example the server was off or the policy was created late, the next run credits the missed months of the current leave year.
  • Run it yourself at any time: System settings → Leave configuration → Credit leave now. It tells you how many credits were added and how many were already done.
  • The server must be running at 02:30 for the automatic run. If it was off, the next night (or the button) catches up.
Comp off is not part of this job. It is credited immediately, the moment a manager approves a day worked on a holiday or weekly off with Eligible for comp off ticked — see section 10.

3. Which rule applies to an employee

For each employee and each leave type, the job asks these questions in order:

Is the employee active, and has their joining date passed?If not, nothing is credited.
Does a leave policy cover them for this leave type?A policy covers someone when its dates include today and its scope matches them (see below). If yes, the policy decides everything: days per year, when they are credited, joiners, rounding, service slabs.
No policy?The leave type's own setting is used: No accrual (nothing), Annual (the whole year on day one) or Monthly (a twelfth each month), with its "days per year".

How a policy finds the employee (its "scope")

Policy fieldMatches this on the employeeWhere that comes from
CountryCountry of employmentEmployee profile → Organization tab
BranchBranchEmployee profile → Organization tab
Employee typeEmployment typeEmployee profile → Employment tab
EmployeeThat one person(an exception for one employee)

Leave a scope field empty to mean "anyone". If several policies match, the most specific one wins (one employee, then a branch, then employee type, then country, then everyone). A statutory policy (required by law) and a company policy can both apply; the employee gets the higher number.

If an employee's Organization tab has no Country of employment, or their Employment tab has no Employment type, a policy scoped to that country or type will not match them.

4. What to set up, in order

Do these once, in this order. Each needs the one before it.

  1. Countries and branchesSystem settings → Countries: add your countries. Administration → Masters → Branches: add each branch and choose its country.
  2. Employee detailsOn every employee's profile set the Country of employment and Branch (Organization tab), and the Employment type and Date of joining (Employment tab). Bulk update can set branch and employment type for many people at once.
  3. Leave yearSystem settings → Leave configuration → Leave year starts in. Choose January for a calendar year, April for April–March, and so on. All balances and expiry follow this.
  4. Leave typesSame page → Add leave type. Create Annual, Casual, Medical, Unpaid and so on (settings in section 5). Leave "Comp off" unticked unless the type is only earned by working on off days. Leave Countries empty unless the type is only for employees working in one or more specific countries.
  5. Leave policiesAdministration → Leave setup → Policies → New policy. Choose who it applies to, the start date, and add each leave type with its days per year and how it is credited (settings in section 6). Create one policy per group that has different rules, for example one per country.
  6. Check one employeeOn the Leave setup → Policies tab, use Check an employee: choose an employee, a leave type and the leave year start. It shows which policy applies and how the days were worked out, month by month, without saving anything. If it says "No policy covers this employee", fix the scope or the employee's details.
  7. Credit leaveSystem settings → Leave configuration → Credit leave now (or wait for 02:30). Then open Administration → Leave setup → Balances for an employee to see the days.
  8. Test as an employeeSign in as an employee, open My leave, and apply. The balance cards show what is available, and the dialog counts the days before you send.

Countries come from System settings → Countries. Leave setup → Policies and Balances always show every leave type regardless of country, since HR there manages any employee.

6. Leave policy settings

Administration → Leave setup → Policies. A policy has who it applies to, its dates, and a rule for each leave type.

The policy

FieldMeaning
KindCompany benefit, or Statutory (required by law). If both apply to someone, they get the higher amount.
Applies toCountry, branch, employee type or one employee. Empty means everyone. See section 3.

The rule for each leave type in the policy

FieldMeaning
Days per yearThe full yearly amount. Half days are fine (for example 1.5).
CreditedWhole year on the first day (upfront), A share each month, or Not credited automatically (you add days by hand).
Joining part-way through the yearNo proration (full year), Completed months (only full months after joining), Started months (the joining month counts), Cut-off day (the joining month counts if they joined by that day), or Exact calendar days.
RoundingNone, down, up, nearest, nearest half day, up to a half day, down to a half day. "Exactly halfway rounds" up or down.

Length of serviceOptional slabs: for example 21 days for the first 60 months, then 30 days. A new slab starts as soon as the milestone is reached, or from the next leave year.
A policy that has already produced credits is locked: you can rename it, end it with an end date or switch it off, but not change its rules. To change a rule, end the policy and start a new one. This keeps earlier calculations explainable.

7. Worked examples

Annual leave, 24 days, monthly

Calendar year, Completed months, no rounding. An employee who joined 16 July earns the full months August to December: 5 × 2 = 10 days. Credits appear as 2 days each on 1 August, 1 September, and so on, as the nightly job runs.

Sick leave, 12 days, upfront

Credited: whole year on the first day. Someone employed on 1 January gets 12 days at once. A joiner in July with Completed months gets 6 / 12 × 12 = 6 days on the first run after they join.

Joined 16 July, 24 days a year

Completed months: 10. Started months: 12. Exact days (169 of 365): 11.11. With Always up to a half day that 11.11 becomes 11.5. Pick the method your company policy uses.

April–March year

Leave year starts in April. A joiner on 1 July with 24 days a year and Completed months earns July to March: 9 × 2 = 18 days.

The page Check an employee (Leave setup → Policies) shows this working for a real employee before you rely on it.

8. Going live part-way through the year

When you start using the system in, say, September, employees already have leave from earlier in the year. There are two honest ways to do it. Pick one, not both.

A. Let the policy catch up

Create the leave policies. The first run credits every month of the current leave year so far (from the year start, or the joining date for later joiners). This gives the full year-to-date entitlement. Then, if someone's real balance differs because they already took leave, add or take away the difference by hand with the reason "Opening balance adjustment".

Recommended when you want entitlements calculated by the system.

B. Type the real balances in

Enter each employee's actual balance by hand (Leave setup → Balances tab), with the reason "Opening balance". Do not create a policy for those leave types until the next leave year starts, otherwise the first run also credits the year-to-date days and the balance is counted twice.

Good when you only have a spreadsheet of final balances.

Check before you press "Credit leave now" the first time. Use Check an employee for two or three people to see the total the policy will give. Credits are written to a ledger and can be corrected by an adjustment, but it is easier not to need one.

9. Adding or removing days by hand

  1. Open the pageAdministration → Leave setup → Balances (HR Admin or System Admin).
  2. Choose the employeeUse the Employees list (it has a search box). You can tick several employees to give them all the same days at once.
  3. Fill "Add or take away days"Pick the leave type, type the days (use a minus sign to take days away, for example -2), write a reason (required), and optionally an Expires date.
  4. SaveThe balance card and the ledger below update at once. Every change is recorded with who, when and why.
  • Days you take away use the balance that expires soonest first.
  • A manual adjustment works for any type that keeps a balance, including a comp off type.
  • Set Expires to the last day of the leave year if the days should not outlive it. Without an expiry date, the days stay until used.

10. Comp off

System settings → Leave configuration → Leave year and comp off.

SettingMeaning
Earn comp off for working on a weekly off or holidayThe switch. Off means nothing is earned.
Days creditedHow many days one qualifying day gives (for example 1, or 0.5).
Expires after (days)How long the comp off stays usable. Empty means it never expires.
Minimum worked (minutes)The day must have at least this much worked time.

You also need a leave type with Comp off ticked to receive the credit. The credit is made immediately, the moment a manager or HR approves the day in Team attendance with the "Eligible for comp off" checkbox ticked in the approve popup — not by a nightly scan. If the day does not actually qualify (not a worked holiday or weekly off, not enough time worked, or comp off switched off), ticking the box does nothing. A comp off credit is not taken back automatically if the attendance is later changed.

Check comp off now (System settings → Leave configuration) is a separate, manual-only tool: it scans the last 45 days for approved worked-holiday/weekly-off days that were never ticked, and backfills a credit for them. Use it to catch up days approved before this checkbox existed, or any missed by mistake. It never credits the same day twice, and it no longer runs automatically at night.

11. How the days are used

  1. ApplyThe employee chooses type and dates on My leave → Apply for leave. The system counts the days (weekly offs, holidays and the sandwich rule included) and checks the balance. Send for approval is only available if the balance covers it, unless the type allows negative balance.
  2. WaitingThe days are reserved (shown as "waiting approval") so they cannot be used twice.
  3. DecisionThe reporting manager, or HR, approves or rejects (Leave Management → Team leave). The days are counted again at approval. Approval takes the days from the balance (the soonest-expiring first) and marks the dates on attendance.
  4. CancelA waiting or future approved leave can be cancelled; the days go back to the balance.
Approval needs the employee to have a reporting manager (Employee profile → Employment tab → Reporting). HR can always decide.

12. When days disappear

Credits made by a policy or by a leave type's own setting expire on the last day of the leave year. The nightly job then closes them and writes an "Expired" line in the ledger, so the employee can see what was lost.

There is no carry-forward yet. Unused days do not move into the next year, and they are not paid out. If your policy lets people carry days forward, tell HR to add the carried days by hand at the start of the new year, with an expiry date, until carry-forward is built.

13. If an employee has no balance

Check these in order:

CheckWhat you will see, and the fix
Is there a policy rule for the type?A leave type set to No accrual with no policy gives nothing. Add the type to a policy, or give the type its own accrual setting.
Is the type marked Comp off?A comp off type is skipped by policies and yearly credit. Edit the type and untick Comp off if it is a normal type such as Casual leave.
Does the policy match the employee?Use Check an employee. If it says no policy covers them, check the policy's country, branch and employee type against the employee's Organization and Employment tabs, and its start date.
Is the leave year right?Leave configuration → Leave year starts in. The year shown by Check an employee must contain today.
Has the credit run?Press Credit leave now. The message says how many credits were added. "0 credited, N already done" means they were created earlier.
Is the employee active, with a past joining date?Inactive employees, or employees whose joining date is in the future, are skipped.
Did the policy produce 0 days?Joining on the last day of a month with Completed months can give 0. Use a minimum ("At least"), or another proration method.
Is the policy switched off or ended?Its "Switched on" box and its end date.
Comp off was not creditedCheck the day was approved with "Eligible for comp off" ticked, the day really worked out to a worked holiday/weekly off, comp off is switched on, and enough time was worked. Already-approved days from before this checkbox existed need Check comp off now instead.

The quickest fix for one person is a manual adjustment (section 9). Fix the cause too, or the next employee will have the same problem.

14. Not built yet

These are not in the system today, so plan around them:

  • Carry-forward of unused days into the next year, and paying out (encashment) of unused days.
  • Probation rules (days locked until confirmation).
  • End-of-service settlement of unused leave.
  • A leave request that crosses two leave years is counted against one balance, not split.
  • Recalculating a whole year when a policy changes in the middle of it. Create a new policy from the change date instead.
  • Payroll. Leave only records the days.

The full list of business questions behind these is in planning/leave_entitlement_requirements.md.
